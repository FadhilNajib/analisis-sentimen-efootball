# Analisis Sentimen Ulasan Pengguna E-Football Menggunakan NLP

## Deskripsi Proyek
Proyek ini bertujuan untuk menganalisis sentimen ulasan pengguna game eFootball menggunakan teknik Natural Language Processing (NLP). Ulasan diproses melalui beberapa tahapan preprocessing sebelum digunakan untuk membangun model klasifikasi sentimen.

## Tahapan Pengerjaan
- Pengumpulan data ulasan pengguna
- Data cleaning dan preprocessing
- Case folding
- Tokenisasi
- Stopword removal
- Stemming menggunakan Sastrawi
- Pelatihan model klasifikasi sentimen
- Evaluasi performa model

## Tools dan Library
- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Sastrawi
- Matplotlib

## Hasil
Model berhasil digunakan untuk mengklasifikasikan sentimen ulasan pengguna ke dalam kategori sentimen tertentu berdasarkan hasil preprocessing dan proses pelatihan model.
